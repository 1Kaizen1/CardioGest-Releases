# CardioGest - versiones

Aqui solo estan los instaladores de CardioGest (pestana **Releases**): un `.zip` y un `version.json` por version.
El codigo esta en el repositorio privado. Las versiones se publican con `publicar.cmd` desde ese repositorio:
no subas nada a mano aqui.

CardioGest busca la ultima version en
`https://github.com/1Kaizen1/CardioGest-Releases/releases/latest/download/version.json`.
